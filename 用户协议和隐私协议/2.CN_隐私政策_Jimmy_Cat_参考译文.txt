2. 可能处理的数据

2.1 账户数据：姓名或昵称、电子邮箱、受保护形式存储的密码、用户标识、角色、语言和界面设置。

2.2 技术数据：IP 地址、浏览器和设备类型、User-Agent、操作日期时间、会话标识、安全日志、故障信息和个人中心操作记录。

2.3 API 使用数据：请求时间、路由、所选模型、响应状态、用量，以及计费、防滥用和诊断所需的信息。请求输入与输出可能会为处理目的而技术性传输给模型供应商；[请明确填写：是否保存请求文本和结果日志、保存地点及期限]。

2.4 支付数据：支付状态、金额、币种、交易标识和支付服务商信息。完整银行卡信息应由支付服务商处理；除非运营者具备合法且技术上充分的理由，否则不应自行处理。

2.5 客服数据：工单内容、附件和联系方式。

2.6 Cookie、本地存储和类似技术：用于登录、安全、保存设置和界面运行的数据。[如将启用分析或广告技术，请明确列出。]

3. 处理目的和法律依据

3.1 运营者可为以下目的处理数据：注册、认证和提供平台功能；创建和保护 API 密钥、记录使用和结算；履行与用户的协议；保障安全、发现欺诈、规则违规和技术故障；回复咨询并履行法定义务；以及在法律允许时基于汇总或匿名数据改进平台。

3.2 处理依据可能包括用户同意、履行合同或协议、履行法定义务、在尊重用户权利前提下的运营者合法利益，或适用法律规定的其他依据。

4. 数据传输与第三方

4.1 运营者可仅为平台运行目的，并在具备适当合同或其他法律依据的情况下，向托管、基础设施、邮件、支付、安全、客服服务商和模型供应商传输必要最小范围的数据。

4.2 法律要求时，数据可能披露给政府机关、法院或其他有权主体。

4.3 使用部分模型和云服务可能涉及跨境传输。运营者须在传输前履行适用法律要求，包括必要的通知或许可。用户不应通过 API 传输在缺乏合法依据时禁止或限制跨境传输的数据。

5. 俄罗斯联邦公民数据

5.1 如运营者通过互联网收集俄罗斯联邦公民的个人数据，应在俄罗斯法律规定的范围和情形下，使用位于俄罗斯联邦境内的数据库，对此类数据进行记录、系统化、积累、存储、更新和提取。

5.2 本节尤其参考俄罗斯联邦 2006 年 7 月 27 日第 152-FZ 号《个人数据法》。运营者应在开始处理前核实是否需要向主管机关提交通知及采取其他强制措施。

6. 保存期限

6.1 数据保存时间不超过实现处理目的、账户有效期、履行义务、处理争议和遵守法定保存义务所需的期限。

6.2 发布前建议明确：账户数据 [期限 / 直至删除账户及其后期限]；安全和 API 日志 [期限]；财务文件 [法定期限]；客服工单 [期限]。只能填写实际执行的期限。

7. 安全措施

7.1 运营者采取合理的组织和技术措施，包括权限控制、账户凭证保护、在使用 HTTPS/TLS 时加密数据传输、安全日志和必要范围的备份。

7.2 任何传输或保存方式都不能保证绝对安全。用户应使用唯一密码，保密 API 密钥，并立即报告疑似未授权访问。

8. 用户权利

8.1 在适用法律规定范围内，用户可请求了解其数据处理情况、访问数据、更正不准确信息、删除、限制处理、撤回同意，以及对运营者的行为提出异议。

8.2 如需行使权利，请发送至 [个人数据联系邮箱]。运营者可要求必要信息以验证请求人身份。

8.3 用户也可依照适用法律向个人数据保护主管机关或法院提出投诉。

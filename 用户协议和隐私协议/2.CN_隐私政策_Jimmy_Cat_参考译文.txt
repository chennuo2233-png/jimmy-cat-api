一、我们处理的信息

根据您使用服务的方式，我们可能处理以下信息：

1. 账户信息：用户名、密码的安全校验信息、账户标识、用户组、余额、权限和账户状态。当前注册不要求提供邮箱。
2. 技术与安全信息：IP 地址、浏览器和设备信息、访问时间、登录记录、请求量、API 密钥的受保护标识、错误代码、延迟、用量和反欺诈/安全事件。
3. API 内容与错误日志：我们不以常规日志方式保存完整 API 请求内容或模型回复。为排查错误、安全事件或滥用，有限的错误日志可能包含与失败请求有关的必要片段、模型标识、时间、状态码或技术上下文。
4. 付款信息：兑换码处理记录，以及加密货币钱包地址、交易哈希、币种、金额、时间、退款和反欺诈处理记录。
5. 您主动提供的信息：您发送给客服的邮件及其附件、账号删除或退款申请所需的资料。

二、处理目的与依据

我们为以下目的处理信息：提供账户与 API 服务；计算和管理余额；排查错误和保障安全；防止欺诈和滥用；处理退款、投诉和权利请求；遵守适用法律和依法提出的请求；以及在必要时维护、改进服务。

我们仅在适用法律允许的基础上处理信息，例如履行与您的服务关系、取得您的同意、遵守法律义务，或为安全和反欺诈目的维护合法权益。依法需要单独同意时，我们将另行征得您的同意。

三、信息的处理地点、第三方与跨境传输

本服务的基础服务器部署在阿里云香港区域。为完成 API 请求，我们可能将必要的请求数据发送给第三方 AI 模型服务提供方处理；这些提供方的处理地点可能位于香港、中国大陆或其他司法辖区。加密货币支付还会通过相应区块链网络公开记录交易信息。

我们不使用广告分析工具或营销邮件服务。我们不会出售您的个人信息，也不会为定向广告而共享个人信息。

跨境传输可能导致您的信息受到接收地法律保护。我们会采取合理的技术和组织措施，并在法律要求时提供必要告知、取得单独同意或采取其他合法机制。请勿通过 API 提交您无权披露的个人信息、国家秘密、金融账户信息或其他高度敏感信息。

四、保存期限

账户及与余额有关的信息通常在账户存续期间保存；账户删除后，我们会在合理必要的期限内删除或匿名化，除非法律、争议、退款、欺诈防范或安全需要要求保留。

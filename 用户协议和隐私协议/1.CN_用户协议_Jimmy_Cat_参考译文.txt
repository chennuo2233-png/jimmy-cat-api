1.4 用户注册、登录个人中心、创建 API 密钥、充值余额或实际使用平台，即表示完整且无条件地接受本协议及隐私政策。

2. 平台服务

2.1 平台提供访问应用程序接口（API）的技术能力，以及对兼容人工智能模型和相关服务的访问管理工具。

2.2 平台并非第三方模型或供应商的开发者、所有者或结果保证人。模型可用性、种类、限额、价格和技术参数可能调整。

2.3 平台仅供合法、善意使用。用户自行确认其传输数据的合法处理依据，并对其请求、应用及最终用户负责。

3. 账户与 API 密钥

3.1 用户须在注册时提供真实信息，并保持其更新。

3.2 API 密钥是保密访问凭证。用户应妥善保管；如怀疑泄露，应立即撤销该密钥。

3.3 在密钥或账户被封禁前，使用该账户或密钥产生的行为视为由用户作出，除非运营者或法律另有认定。

3.4 在法律、支付服务商规则或反滥用需要的情形下，运营者可要求额外核验身份、权限或付款来源。

4. 付费与结算

4.1 若平台提供付费功能，价格、币种、计费与扣款规则应在个人中心或支付页面、且在付款前展示。

4.2 用户应在发送请求前自行核对适用价格与规则。调用 API 可能按照展示的条件扣费。

4.3 支付数据由支付服务商处理。除安全支付页面外，运营者不应索取银行卡信息。

5. 合法使用

5.1 用户须遵守适用法律、第三方权利、模型供应商规则及本协议。

5.2 禁止将平台用于：违法行为；欺诈、钓鱼、欺骗、窃取数据或绕过安全措施；露骨色情、性剥削或任何涉及未成年人的相关内容；血腥暴力、威胁或伤害他人的材料；侵犯知识产权、隐私、名誉或商誉；恶意代码、基础设施攻击、垃圾信息、绕过限额或未授权访问；未经必要同意或合法依据处理数据；以及其他被法律、平台或模型供应商规则禁止的行为。

5.3 平台可采取自动或人工安全措施，包括内容过滤、限速、暂停请求、撤销密钥和封禁账户。

6. 内容与安全

6.1 用户对其请求、输入数据、文件、指令和生成结果负责。

6.2 除非确有必要并受单独书面协议保护，请勿通过 API 传输密码、API 密钥、支付信息、政府身份证件、敏感个人信息或其他机密信息。

6.3 为遵守法律、保护平台、用户、第三方或防止损害，运营者可不经预先通知限制或终止访问。

7. 知识产权

7.1 平台的软件、设计、商标和其他材料的权利归运营者或相应权利人所有。

7.2 用户对其合法传输的输入数据保留适用法律及模型供应商协议允许的权利。

7.3 用户保证对传输的数据拥有必要的权利和授权，并对侵犯第三方权利承担责任。

8. 免责声明与责任限制

8.1 在法律允许范围内，平台按“现状”和“可用状态”提供。运营者将采取合理措施维持服务，但不保证持续无中断、无错误、特定模型可用，或结果适用于某一特定目的。

8.2 AI 结果可能不准确、不完整或不适合作为决策依据。尤其是医疗、法律、金融、人事和其他重大场景，用户必须自行核验结果。

8.3 本协议不限制法律不允许限制的责任。在其他情形下，运营者的责任以导致索赔事件前 [请填写期间，例如 3] 个月内用户实际支付的平台费用为限。

9.1 个人数据依照平台隐私政策及适用法律处理；在适用时包括俄罗斯联邦 2006 年 7 月 27 日第 152-FZ 号《个人数据法》。

10. 暂停与终止访问

10.1 用户可按照个人中心提供的方式停止使用、删除账户，或向运营者发送请求。

10.2 用户违反协议、法律要求、出现安全风险、未付款或平台停止运营时，运营者可暂停或终止访问；可行时会说明原因及后续处理方式。

11.1 运营者可修改本协议，并会在平台发布新版本和生效日期。

11.2 在修改生效后继续使用平台，视为接受新版本；法律另有规定的除外。
